# DEMO FLOW

This document outlines the intended final demonstration sequence for the hackathon.

1. Heavy rainfall begins
2. Predictive Agent identifies increasing risk
3. Citizen submits SOS
4. Situation Agent understands incident
5. Risk Agent assigns priority
6. Resource Agent selects ambulance/rescue team
7. Route Agent calculates route
8. Hospital capacity is checked
9. Master Coordinator creates response plan
10. Operator approves
11. Dispatch occurs
12. Road becomes blocked
13. System detects change
14. Route is recalculated
15. Hospital becomes full
16. Alternative hospital is selected
17. Offline citizen sends SOS
18. Message travels through BLE relay phones
19. Gateway syncs message
20. AI pipeline processes it
21. Incident is resolved
22. Actual outcome is stored for future learning
